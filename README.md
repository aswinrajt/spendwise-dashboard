# SpendWise Dashboard

SpendWise — Personal Finance Dashboard UI

Build a modern, clean, responsive personal finance management web app called SpendWise.

Create these pages:

Dashboard

Transactions

Budgets

Categories

Dashboard should include:

Total income

Total expenses

Current balance

Monthly budget

Monthly income vs expense chart

Category-wise expense chart

Recent transactions

Budget progress cards

Transactions page:

Table of transactions

Add Transaction button

Income/Expense type

Amount, category, date, description

Search and filter

Edit and delete actions

Budgets page:

Monthly budget cards

Spending progress

Remaining amount

Add/Edit budget

Categories page:

Expense categories with icons

Category spending totals

Add/Edit/Delete category

Use a professional SaaS-style dashboard with a sidebar, top navigation, cards, charts, tables, modals, responsive mobile layout, good spacing, and polished typography.

For now, use realistic mock data only. Do not build authentication or backend functionality. Focus entirely on the frontend UI and make every button/modal visually functional.
